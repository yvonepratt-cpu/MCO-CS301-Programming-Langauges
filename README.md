# MCO-CS301-Programming-Languages

This project takes one application, a calculator, and implements it in two
different programming languages to compare how each one handles the same task.

## Files

| File | Language | Description |
|------|----------|-------------|
| `calcu.py` | Python | Calculator that runs in the terminal |
| `calculator.html` | HTML / JavaScript | Calculator that runs in the browser |
